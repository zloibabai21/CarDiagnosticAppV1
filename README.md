# CarDiagnosticAppV1

## Описание проекта

CarDiagnosticAppV1 — программный модуль определения автомобиля и диагностического протокола связи, разработанный в рамках курсового проекта по дисциплине «Технологии разработки программного обеспечения».

Модуль является частью программно-аппаратного комплекса диагностики автомобилей и предназначен для автоматического определения диагностического протокола на основе выбранной пользователем марки, модели и года выпуска автомобиля.

---

## Функциональные возможности

- Выбор марки автомобиля
- Выбор модели автомобиля
- Выбор года выпуска
- Определение диагностического протокола
- Отображение результатов пользователю
- Очистка формы
- Проверка поддерживаемых автомобилей

## Запуск приложения

1. Открыть проект в IntelliJ IDEA.
2. Убедиться, что установлен JDK 17.
3. Запустить класс:

```java
Main.java
```

4. Выбрать автомобиль.
5. Нажать кнопку:

```text
Определить протокол
```

## Тестирование

Для тестирования используется библиотека JUnit 5.

Реализованы автоматические тесты:

- Toyota Camry → UDS
- Toyota Corolla → UDS
- BMW X5 → ISO15765
- Audi A6 → UDS
- Неподдерживаемый автомобиль → сообщение об ошибке

Все тесты выполняются успешно.
